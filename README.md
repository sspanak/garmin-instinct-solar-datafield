# Garmin Instinct Solar datafield
Solar energy and battery logging in activities, optimized for low-memory usage on Garmin Instinct series. 

It's a fork of [baito's widget](https://github.com/fabiobaltieri/ciq-solar-logger) modified to save all data as integers.

Install from Connect IQ: https://apps.garmin.com/apps/cf23f257-8d1d-485d-984a-5d5fb8ce2725
